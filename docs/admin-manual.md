# 后台操作手册

本手册面向族谱维护者，按功能模块说明后台的入口、操作步骤与预期结果。所有操作均在 `/admin` 下完成，前台不提供管理入口。

约定：

- 「超管」指超级管理员，「普通管理员」指被指定了所属族谱的管理员
- 步骤中的按钮文案与界面原文一致，可直接对照
- 保存类操作成功后，页面顶部会出现绿色提示；失败时为红色提示

## 一、登录与账号安全

### 1.1 登录

1. 访问 `/admin/login`
2. 输入账号与密码，点击「登录」
3. 若账号已启用验证器，继续输入验证器 App 中的 6 位动态码

首次使用超级管理员账号登录时，系统要求先绑定验证器；未绑定前无法进入其他页面。初始密码由首次启动日志输出，或由部署时的 `INITIAL_ADMIN_PASSWORD` 指定。

### 1.2 修改密码

1. 左侧菜单进入「安全设置」
2. 在「修改密码」区域填写当前密码、新密码、确认新密码
3. 点击「更新密码」

新密码至少 8 位，两次输入必须一致，否则提示「两次输入的新密码不一致」。修改成功后，其他设备上的旧会话随即失效，需要用新密码重新登录。

### 1.3 启用或关闭验证器

1. 左侧菜单进入「安全设置」
2. 在验证器区域点击「启用验证器」
3. 使用验证器 App 扫描二维码，输入 6 位动态码，点击「确认启用」

关闭验证器需先输入当前登录密码，再点击「关闭验证器」。超级管理员必须启用验证器，界面会标注「超级管理员必须启用」；普通管理员可自行选择。

### 1.4 退出登录

侧边栏底部提供两种退出方式：

- 「退出登录」：仅结束当前设备的会话
- 「退出全部设备」：使该账号在所有设备上的会话失效

## 二、界面与导航

左侧菜单按固定顺序排列，超管与普通管理员可见范围不同。

| 菜单 | 路径 | 可见角色 |
| --- | --- | --- |
| 概览 | `/admin` | 全部 |
| 家族管理 | `/admin/families` | 全部 |
| 成员管理 | `/admin/members` | 全部 |
| 反馈审核 | `/admin/submissions` | 全部 |
| 安全设置 | `/admin/account` | 全部 |
| 网站设置 | `/admin/site` | 超管 |
| 管理员 | `/admin/admins` | 超管 |
| 操作日志 | `/admin/audit` | 超管 |
| 证书域名 | `/admin/domains` | 超管 |

超管管理的族谱多于一部时，顶部提供族谱切换器。切换后，「成员管理」「反馈审核」等页面只显示所选族谱的数据。普通管理员的账号固定绑定一部族谱，无切换器。

## 三、族谱管理

入口：左侧菜单「家族管理」。该页列出全部族谱，点击「新建族谱」进入新建页；点击已有族谱的名称进入编辑页。

编辑页自上而下分为若干区域，修改后点击「保存修改」；新建时按钮为「建立族谱」，保存成功后提示「族谱已建立，可继续录入族人」。

### 3.1 家族信息

| 字段 | 要求 | 说明 |
| --- | --- | --- |
| 家族标签 | 必填 | 用于区分族谱，全站唯一，如「陈氏」 |
| 家族名号 | 选填 | 用于导航、标题与题识，如「颍川陈氏」 |
| 堂号 / 郡望 | 选填 | 如「德星堂」「颍川」 |
| 祖籍地 / 世居地 | 选填 | 显示于首页题识 |
| 始迁祖 | 选填 | 如「陈德元」 |
| 始迁 / 立谱年代 | 选填 | 支持「明万历三年」这类文本 |
| 字辈派语 | 选填 | 以空格或「·」分隔 |

「姓氏」字段取首字作为方印标识。

### 3.2 标识与访问

「路径标识 slug」决定前台地址，须为 2–32 位小写字母、数字或连字符，填写不合规时提示「slug 需为 2–32 位小写字母、数字或连字符」。

访问方式三选一：

| 方式 | 前台表现 |
| --- | --- |
| 公开 | 任何人可直接查阅世系，无需口令 |
| 密码 | 访客输入访问口令后可查阅世系；口令由系统随机生成 |
| 私密 | 仅登录的管理员可在后台查阅，前台不展示世系；仅超管可设置 |

口令相关行为：

1. 首次将访问方式设为「密码」时，保存后自动生成口令，提示「已保存，访问口令已自动生成」，并显示口令明文；明文仅显示一次
2. 由公开或私密切回「密码」时，若已有口令，则沿用原口令，提示「已保存，沿用原访问口令；如已遗失请点「重新生成」」
3. 点击「重新生成」会立即签发新口令，旧口令与新口令同时失效前的凭证一并作废
4. 访问凭证有效期为 24 小时，且绑定当前口令；口令轮换后，此前已解锁的访客需重新输入

「排入出嫁女子后裔（外衍）」默认关闭。开启后，出嫁女子的后裔续排子女、孙辈两层，纳入世系图与谱页；关闭时仅收录本族血脉，出嫁女子只记本人。

### 3.3 展示与主谱

该区域仅超管可修改，普通管理员看到的是只读状态。

- 「在门户公开展示此族谱」：开启后门户列出该族谱；关闭后整部从前台隐藏，后台不受影响，地址访问按「不存在」处理
- 「设为主谱」：门户与登录页优先展示该族谱，全站仅一部主谱

### 3.4 派系与房支

用于集中维护家族各派。为每房指定一位「房主」（先祖）后，前台世系图按该房主的血统子树自动展示其全部后裔，包含媳妇与女婿，无需逐人标注房支；未指定房主时，按族人档案中的房支标签匹配。

操作步骤：

1. 在派系区域新增一行，填写房支名称，如「长房」
2. 通过「指定房主（先祖）」选择该房先祖
3. 点击「应用对齐」，等待提示完成

选择房主时下方会提示「指定房主（先祖）：系统将自动展示其全部后裔」。若对齐失败，页面提示「对齐失败」，通常由房主已被其他派系占用或该族人已删除导致。

### 3.5 文献

四个多行文本字段，均显示在前台首页与「家族文献」页：

- 家族简介 / 源流：分段请直接换行，前台按段呈现
- 家训：每行一句
- 家规
- 谱序

### 3.6 站点

「页脚文字」用于前台页脚与题识，如「颍川陈氏德星堂 · 家族族谱」。新建族谱时，系统会按名号生成默认值，可直接修改。

### 3.7 校验结果

保存后建议在前台核对三项：

1. 门户列表是否出现该族谱（取决于公开开关与访问方式）
2. `/t/:slug` 是否可访问，密码访问时是否要求输入口令
3. 世系图是否按预期展示房支

## 四、成员管理

入口：左侧菜单「成员管理」。页面顶部为工具栏，依次为「导入族人」「导出族人」「新增族人」；筛选栏提供姓名或字号搜索、世次、房支三个条件；列表支持分页与「全选本页」。

### 4.1 筛选与选择

- 三个筛选条件可组合使用
- 修改任一筛选条件后，已勾选的成员会被清空，避免批量删除时误删视野外的族人
- 「全选本页」只作用于当前页

### 4.2 新增与编辑族人

1. 点击「新增族人」，或在列表行点击「编辑」
2. 填写基本信息：姓名为必填项；世次为必填项，可按父辈推导
3. 可选填写字号、字辈、房支、性别、功名、生年、卒年、葬地与生平
4. 在亲属关系区域选择父、母、配偶
5. 点击「保存修改」

亲属关系有两条约束：

- 父辈与配偶的选择不可指向本人或其后代
- 若所选的母亲与父亲不是配偶关系，系统会询问是否「同步为父亲的配偶」；反之询问是否「同步为母亲的配偶」。选择同步后，两人的配偶关系一并建立

头像为可选项：选择图片后可裁剪区域与比例，系统自动压缩为 WebP；无头像时以姓名末字占位。

### 4.3 删除族人

单条删除点击行内「删除」，批量删除勾选后点击「批量删除」，两者都会弹出「确认删除」。删除不可撤销，且会同时影响引用该族人的亲属关系。

### 4.4 导入族人

1. 点击「导入族人」
2. 选择 Excel 文件，系统解析后展示预览表格
3. 核对预览无误，点击「确认导入」

模板列为：编号、姓名、性别、世次、房支、父、母、配偶、备注。

- 父、母、配偶填写对应族人的编号，并以 `@` 引用，如 `@A003`
- 世次可留空，由父辈编号推导
- 性别填写「男」或「女」
- 解析失败时提示「文件解析失败」；写入阶段任一行不合法时整体回滚，提示「导入失败，未写入任何行」
- 导入成功后提示「族人导入完成，名录已刷新」，列表自动重新加载

### 4.5 导出族人

点击「导出族人」，导出当前筛选条件下的全部族人，不受分页限制。当前筛选为空时提示「当前筛选下没有可导出的族人」。超管可先切换族谱再导出，普通管理员只能导出所属族谱。

## 五、反馈审核

入口：左侧菜单「反馈审核」。前台「信息反馈」提交的内容在此审核。

### 5.1 筛选

可按状态下拉筛选：全部、待审、已采纳、已驳回；超管还可按所属族谱筛选。列表显示编号、反馈人、所属族谱、提交时间与状态。

### 5.2 查看详情

点击记录展开详情，字段包括：姓名、性别、世次、字号、房支、功名、父、母、配偶、生年、卒年、葬地、简介，以及「原始资料(JSON)」。后者为提交时的完整结构化数据，字段与成员表单对应，便于手工比对。

### 5.3 处理反馈

- 「审核反馈」：标记为已采纳或已驳回
- 「删除」与「批量删除」：删除前弹出「确认删除」
- 「导出」：按当前筛选导出记录；无可导出记录时提示「没有可导出的记录」

采纳反馈不会自动修改族人档案，仍需在「成员管理」中手动修订。建议流程为：审核通过后在成员管理编辑对应族人，再回到反馈页标记为已采纳。

## 六、网站设置（仅超管）

入口：左侧菜单「网站设置」。该页保存后多数字段即时生效，无需重启。

| 区域 | 作用 | 保存后提示 |
| --- | --- | --- |
| 网站名称 | 全站标签页标题与水印 | 已保存，全站标签页标题与水印即时更新 |
| 备案信息 | 前台页脚展示的备案号 | 已保存，前台页脚刷新后同步展示 |
| 站点图标 | 上传 PNG/JPG/WebP/ICO/SVG，上限 256KB | 已更新站点图标，浏览器标签页即时生效 |
| 访问统计 | 填写统计服务站点标识 | 已保存，全站统计接入即时更新 |
| 反馈入口 | 开启或关闭全站反馈 | 已开启，全站反馈入口即时恢复 / 已关闭，全站反馈入口即时隐藏 |

注意事项：

- 网站名称不能为空，否则提示「网站名称不能为空」
- 备案信息需先存在主谱，未设置主谱时提示「未找到主谱，无法保存备案信息」
- 上传非图片文件时提示「请选择图片文件（PNG/JPEG/WebP/ICO/SVG）」；超过 256KB 时提示「图标体积过大（上限 256KB）」
- 清除自定义图标可点击对应按钮，恢复默认图标，提示「已清除自定义图标，恢复默认」
- 访问统计可自定义该服务商在《隐私说明》中的说明文案，留空则使用默认模板

## 七、管理员账号（仅超管）

入口：左侧菜单「管理员」。

### 7.1 创建管理员

1. 填写账号与密码，密码至少 6 位
2. 选择角色：超级管理员或普通管理员
3. 选择为普通管理员时，必须指定所属家族，否则提示「请为普通管理员选择所属家族」
4. 点击「创建」

### 7.2 修改与停用

- 将账号在「超级管理员」与「普通管理员」之间切换时，若改为普通管理员而未选择家族，提示「请先为该账号选择所属家族，再设为普通管理员」
- 「启用」与「停用」控制账号能否登录，停用后已有会话失效

### 7.3 重置密码与删除

- 「重置密码」：输入新密码，至少 6 位，确认后提示「确认重置」
- 「删除」：删除账号后不可恢复

管理员的所有上述操作都会写入「操作日志」。

## 八、证书域名（仅超管）

入口：左侧菜单「证书域名」。用于为族谱绑定自有域名并查看证书状态。

### 8.1 绑定域名

1. 输入域名，如 `genealogy.example.com`
2. 点击「确认绑定」
3. 按部署文档配置 DNS 解析，指向本服务所在服务器

### 8.2 状态说明

| 状态 | 含义 | 处理建议 |
| --- | --- | --- |
| 待签发 | 已绑定，尚未触发签发 | 确认 DNS 已生效后等待签发 |
| 签发中 | 证书脚本正在申请 | 等待，通常数分钟内完成 |
| 已生效 | 证书已签发并部署 | 可直接通过该域名访问 |
| 续期中 | 正在自动续期 | 无需处理 |
| 失败 | 签发失败 | 检查 DNS 解析与 `INTERNAL_API_TOKEN` 配置 |

列表中同时显示到期时间与证书路径，便于排查证书文件位置。删除域名需在「确认删除」中确认，删除后该域名不再由本服务响应。

## 九、操作日志（仅超管）

入口：左侧菜单「操作日志」。记录管理员的关键操作与登录行为。

### 9.1 可记录的动作

删除反馈、导出反馈、审核反馈、创建管理员、变更管理员、删除管理员、重置密码、创建族谱、更新族谱、创建族人、更新族人、删除族人、导入族人、登录、导出审计日志。

### 9.2 查询

1. 选择动作，默认为「全部动作」
2. 可选填写操作人账号
3. 选择时间条件：全部、按年份、按年月；选择年份或年月时须填写对应数值，否则提示「请先填写查询年份」
4. 点击「查询操作日志」

时间条件同时作用于查询与导出。点击「清空」可清除条件并隐藏结果。

### 9.3 导出

点击「导出审计日志」按当前条件导出 CSV。导出前必须填写年份，否则提示「请先填写导出年份」。导出行为本身也会被记录。

## 十、常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 侧边栏缺少「网站设置」「管理员」等菜单 | 当前账号为普通管理员 | 使用超管账号操作，或由超管调整角色 |
| 切换家族后成员列表为空 | 该族谱尚未录入族人 | 在「成员管理」新增或导入 |
| 保存访问方式后没有出现新口令 | 切回密码访问时沿用了原口令 | 查看提示文案；需要新口令时点「重新生成」 |
| 族人口令正确但被拒绝访问 | 管理员已轮换口令，旧凭证失效 | 向管理员索取新口令 |
| 世系图为空或缺少房支 | 房主未指定，或房支标签与族人档案不一致 | 在「派系 / 房支」指定房主并「应用对齐」 |
| 导入提示未写入任何行 | 任一行校验失败，整体回滚 | 按预览中的错误行修正后重新导入 |
| 反馈已采纳但族人信息未变 | 审核状态与档案数据相互独立 | 在「成员管理」手动修订族人档案 |
